# corgo-mcp-knowledge

Read/query MCP server for the Corgo engine workspace.

Use this server when you want the model to:
- Look up Corgo engine APIs and repo conventions
- Find examples and snippets in the workspace
- Suggest where new code should live
- Validate a proposed change against the current project layout

## Install

```powershell
cd tools/corgo-mcp-knowledge
npm install
```

## Quick check

```powershell
npm run self-check
```

## Run as MCP server

```powershell
npm start
```
