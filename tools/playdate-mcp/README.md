# playdate-mcp

Read/query MCP server for the Playdate SDK and Corgo's Playdate integration.

Use this server when you want the model to:
- Look up Playdate API usage from the installed SDK headers
- Find Playdate examples and snippets in the workspace
- Suggest where Playdate-specific code belongs
- Validate Playdate integration details such as SDK path and bundle layout

## Install

```powershell
cd tools/playdate-mcp
npm install
```

## Quick check

```powershell
npm run self-check
```

## Run as MCP server

```powershell
npm start
```
